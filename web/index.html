Real Android 13, running in this tab.

1Description

An engine written in C and compiled to WebAssembly runs Android's own ARM64 programs and answers their Linux system calls itself: binder, futexes, files, input devices, the emulator's graphics pipe. OpenGL ES goes to WebGL2.

A booted snapshot restores straight to the home screen. Then open the app drawer, Settings, Files or Calculator.

2Features

  • Android 13 (AOSP): launcher, SystemUI, Settings, Files, Calculator
  • Touch, swipe and physical keyboard input
  • Restores a booted snapshot, delivered as content-addressed chunks
  • Runs on your machine: nothing is streamed from a server-side phone

5How it works

The engine

There is no virtual machine and no kernel. The engine runs Android's ARM64 user-space programs, translating hot code to WebAssembly, and implements the Linux interface they call: processes and threads, memory, files, futexes, binder, input devices and the goldfish graphics pipe.

The snapshot

Android was booted once to its home screen and its memory saved. Start Android downloads that snapshot and restores it, so the phone starts where the boot ended instead of booting for minutes. When the snapshot does not match this engine, the page boots Android instead and says so.

Chunks

The system image and the snapshot are cut into content-addressed chunks, packed in the order they are first read. The boot's chunks are kept in your browser's cache, and a chunk the phone needs later is read on demand.

GL to WebGL2

Android draws with OpenGL ES through the emulator's graphics pipe. The engine replays those calls on WebGL2 and SurfaceFlinger's composed frame is drawn on the page, 540 × 960 at 240 dpi.

Input

Pointer and keyboard events on the screen become Linux evdev events in a ring the engine reads, so Android sees a touchscreen and a keyboard. Back and Home send the phone's own keys.

6Known limits

Network
Off in this build: apps see no connection.
Audio
None: the audio HAL is a null device.
Browsers
Chromium-based browsers. The page needs cross-origin isolation, SharedArrayBuffer and WebGL2.
Devices
Desktop first. There is no on-screen keyboard yet; type with a physical one.
First start
A download of about 142 MB before the phone appears. When there is no snapshot for this engine, Android boots from the start, which takes minutes.
